# Logotipo

Carpeta reservada para el logotipo oficial en SVG o PNG de alta calidad.

La marca del header y del footer en `index.html` es una representación tipográfica
temporal con un rayo, montada en HTML/CSS. Cuando se reciba el archivo definitivo:

1. Guardarlo aquí como `logo-uzabal.svg` (o el nombre que se prefiera).
2. Reemplazar el bloque `.brand` del header y del footer en `index.html` por:
   ```html
   <img src="assets/images/logo/logo-uzabal.svg" width="180" height="56" alt="UZABAL SURGE SOLUTIONS">
   ```
3. Actualizar `assets.logo` en `assets/js/config.js`.

No modificar la paleta ni las tipografías de los tokens.
