# Fotografía institucional

Carpeta reservada para la fotografía de Felipe / imagen institucional definitiva.
La sección «Nosotros» usa actualmente el manifiesto institucional y mantiene oculta
la estructura `.about__future` para información profesional futura (sin datos de relleno).

Cuando se reciba la foto:

1. Guardarla aquí como `felipe.jpg` (o el nombre definitivo).
2. Agregar una figura con `<img src="assets/images/institutional/felipe.jpg" alt="…">`
   en la sección `#nosotros` de `index.html`, dentro de `.manifesto__grid`.
3. Actualizar `assets.institutional` en `assets/js/config.js`.
