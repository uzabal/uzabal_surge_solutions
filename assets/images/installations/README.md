# Fotografías de instalaciones

Carpeta reservada para fotografías reales de instalaciones eléctricas, si se deciden
incorporar. No se publicaron imágenes genéricas como si fueran instalaciones de UZABAL.

Cuando se reciban:

1. Guardarlas aquí, por ejemplo `instalacion-principal.jpg`.
2. Insertarlas en la sección que corresponda de `index.html` con un `alt` descriptivo.
3. Actualizar `assets.installation` en `assets/js/config.js`.
